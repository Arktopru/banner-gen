# banner-gen

TUI/CLI генератор ASCII-баннеров для Spring Boot (`banner.txt`).

Работает **полностью офлайн**: в пакет вшиты 335 официальных figlet-шрифтов
из коллекции patorjk — те же, что на его генераторе, только ничего не
отваливается. Шрифты лежат в `banner_gen/fonts/*.flf`.

## Установка

```bash
cd ~/Projects/asciiart
python3 -m venv .venv
.venv/bin/pip install -e .
```

Алиас для запуска из любой папки (уже добавлен в `~/.zshrc`):

```bash
alias banner-gen="$HOME/Projects/asciiart/.venv/bin/banner-gen"
```

## TUI

```bash
banner-gen
```

Экран:

```
┌──────────────────────────────────────────────────────────────┐
│ [текст баннера…]                                  [отступ]   │
├──────────────┬───────────────────────────────────────────────┤
│ [поиск…]     │                                               │
│ Standard     │        ██╗ ██████╗ ██████╗                    │
│ Slant        │        ██║ ██╔══██╗██╔═══██╗                  │
│ ANSI Shadow  │        ██║ ██████╔╝██║   ██║                  │
│ …            │        ╚═╝ ╚═════╝ ╚═╝   ╚═╝                  │
├──────────────┴───────────────────────────────────────────────┤
│ ANSI Shadow · 24×6                                           │
└──────────────────────────────────────────────────────────────┘
```

- Текст и шрифт меняются — превью перерисовывается мгновенно
- Поиск слева фильтрует список шрифтов, стрелки `↑`/`↓` листают его
- «отступ» — сколько пробелов добавить слева (у классических баннеров — 1)
- В статусной строке — размеры арта; если шире 80 колонок, предупреждение
  (в консоли такой баннер может перенестись)

Клавиши:

| Клавиша  | Действие                                   |
|----------|--------------------------------------------|
| `Ctrl+C` | скопировать ASCII-арт в буфер обмена       |
| `Ctrl+S` | сохранить в файл (открывается диалог пути) |
| `Ctrl+Q` | выход                                      |
| `F1`     | справка по клавишам                        |

Последние текст, шрифт, отступ и путь сохранения запоминаются в
`~/.config/banner-gen/config.json`, при следующем запуске всё восстанавливается.

## CLI

```bash
banner-gen 'my-app'                        # показать в терминале
banner-gen 'my-app' -f Standard --indent 1
banner-gen 'my-app' -f Standard -o src/main/resources/banner.txt  # в файл проекта
banner-gen 'my-app' -f 'ANSI Shadow'       # другим шрифтом
banner-gen 'my-app' --copy                 # в буфер обмена
banner-gen --search shadow                 # найти шрифт
banner-gen --list                          # все 335 шрифтов
banner-gen --help                          # полная справка
```

Полный список опций — `banner-gen --help`.

## Как это работает

- Рендеринг — `pyfiglet` (движок figlet: кернинг, smushing), шрифты — `.flf`
  файлы из официальной коллекции figlet в зеркале
  [patorjk/figlet.js](https://github.com/patorjk/figlet.js)
- Копирование в буфер — через `pbcopy` (macOS)
- Для Spring Boot ничего специального не нужно: `banner.txt` кладётся в
  `src/main/resources/` модуля, который стартует (например web-модуля),
  и подхватывается при старте
